# Alarm Clock for BRover E5

Программный модуль будильника для образовательного робота-ровера **BRover E5** от VoltBro. 

Программа работает в экосистеме **ROS 2** и использует `cyphal_ros2_bridge` для прямого взаимодействия с аппаратными компонентами ровера: встроенной кнопкой пользователя (`/user_button`) и звуковым излучателем (`/hmi/beep`) [[2]].

## Особенности

- ⏰ **Гибкая настройка**: Время срабатывания задаётся в простом JSON-файле.
- 🔊 **Аппаратное оповещение**: Использует штатный beeper ровера через Cyphal-сервисы.
- 🛑 **Аппаратное отключение**: Будильник отключается только при физическом нажатии кнопки пользователя (User Button) во время звукового сигнала.
- 📊 **Информативность**: Выводит в консоль текущее время и обратный отсчёт до следующего срабатывания.
- ⚙️ **Автономность**: Работает как фоновый системный сервис (`systemd`), не требуя постоянного открытого терминала.

## Требования

- Робот-ровер **BRover E5** (на базе Raspberry Pi 5) [[1]].
- Установленная и настроенная среда **ROS 2** (Jazzy) [[2]].
- Активный узел `cyphal_ros2_bridge` для связи с CAN-шиной ровера.
- Python 3.
